ENUMERAZIONE - Fase più importante

Se fallisci qui, perdi la CTF - Non si può andare avanti nella ricerca. Tool Fondamentali:

  • nmap - Port scanning + service detection.
  • gobuster / dirsearch - Directory brute-force web.
  • nikto - Vulnerability scanner web.

WEB EXPLOITATION

Molte room sono web-based. Tool Fondamentali:

  • Burp Suite - Intercetta richieste HTTP e Manipolazione parametri.
  • curl - Test rapido endpoint.
  • browser dev tools - JS analysis, cookies, storage.

Burp è praticamente obbligatorio per XSS, IDOR, auth bypass.

Top 10 MUST-HAVE

Tool Importanti:

  • nmap - Scopo: Scansione porte e servizi - Scopre: porte aperte, servizi (SSH, HTTP, FTP…), versioni vulnerabili
  • gobuster - Scopo: Scansione directory web - Se trovi HTTP Scopre: directory nascoste (/admin, /login), file sensibili
  • Burp Suite - Scopo: Intercettare e modificare richieste HTTP - Per Web exploitation Serve per: XSS, SQLi, IDOR, bypass login
  • netcat - Scopo: Gestire shell e connessioni - Dopo exploit Serve per: reverse shell, bind shell, listener
  • hydra - Scopo: Brute force login - Quando hai username o servizio login Supporta: SSH, FTP, HTTP login
  • hashcat - Scopo: Crack hash - Quando trovi hash Supporta: MD5, SHA, bcrypt
  • searchsploit - Scopo: Cercare exploit pubblici - Dopo aver identificato servizio/versione
  • linpeas - Scopo: Privilege escalation (Linux) - Dopo aver ottenuto accesso Trova: SUID, cron jobs, misconfigurazioni
  • python - Scopo: Scripting e exploit custom
  • wireshark - Scopo: Analisi traffico di rete - Forensics / challenge di rete Serve per: analizzare pacchetti, trovare credenziali, ricostruire traffico

Con questi copri la maggior parte delle challenge. Workflow (enumeration → exploit → escalate)

WORKFLOW COMPLETO CTF

  1. ENUMERAZIONE INIZIALE (Sempre)
    • Nmap: Appena ottieni IP; Obiettivo: Porte aperte, servizi attivi e versioni.
  2. Se trovi HTTP -> Enumerazione Web
    • Gobuster: Se Nmap mostra porta 80/443; Obiettivo: trovare entry point nascosti: Cerchi: /admin, /login, /uploads.
    • Burp Suite dopo aver trovato pagine web; Obiettivo: Exploit vulnerabilità; Usalo per: login bypass, parametri tampering; XSS/SQLi
  3. Se trovi Login -> Attacchi credenziali
    • Hydra: hai login (SSH, FTP,web); Obiettivo: Ottenere accesso.
    • Hashcat Trovi hash; Obiettivo: convertirli in password.
  4. Accesso alla macchina (Foothold)
    • Netcat: hai exploit o credenziali; Obiettivo: Ottenere shell.
  5. Dopo Accesso -> Privilege Escalation
    • LinPEAS: Appena hai una shell; Obiettivo: Diventare Root; Cerca: SUID, cron job, sudo misconfig.
  6. Se non hai Exploit -> Cerca Vulnerabilità
    • Searchsploit: Conosci servizio + versione; Obiettivo: Trovare exploit pronti.
  7. Automazione/Custom Exploit
    • Python: quando exploit non esiste o va adattato.
  8. (Se serve) Analisi avanzata
    • Wireshark: Challenge forensics/network; Obiettivo:analizzare traffico.
