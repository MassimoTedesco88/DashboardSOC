Linux Filesystem

  • /root - the home directory of the all-powerful root user
  • /boot - Kernel image
  • /etc - generally contains the Linux conf. files - files that control when and how programs start uo
  • /home - The user's home dir.
  • /mnt - Where other filestystems are attached or mounted to the Filesystem
  • /proc - View of internal kernel data
  • /sys - Kernel's view of the hardware
  • /dev - Special device files
  • /bin - Where application binaries reside
  • /sbin - Binaries
  • /lib - Where you'll find libraries
  • /usr
    • /sbin
    • /bin
    • /lib
