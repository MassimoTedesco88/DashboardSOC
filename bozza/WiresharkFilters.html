Wireshark Filters

  • 1.Traffico sospetto / anomalo
    • !(ip.addr == 192.168.1.0/24) - IP/MAC sconosciuti- Mostra traffico che non appartiene alla tua rete
    • http or https or dns or tls -Traffico verso Internet non usuale- Aiuta a identificare comunicazioni verso domini esterni
  • 2. DNS - Ricerca di C2, phishing o tunneling
    • dns - Richieste DNS
    • dns.qry.name contains "." - DNS verso domini sospetti o lunghi (tunneling DNS)
    • dns.flags.rcode !=0 - Errori DNS (indicativo di malware che tenta domini inesistenti)
  • 3.TLS - Controllo del traffico cifrato anomalo
    • tls - tutte le connessioni TLS
    • tls.handshake.certificate - Certificati self-signed o insoliti
    • tls.handshake.extensions_server_name - SNI utile per identificare il dominio
  • 4.Comportamenti tipici del malware (C2/beaconing)
    • tcp.flags.syn == 1 - Conessioni ripetute verso lo stesso IP (aiuta a identificare beaconing periodico)
    • tcp.analysis.keep_alive - Connessioni brevi e costanti
  • 5. HTTP - Phishing, exfiltration, download payload
    • http - tutto il traffico
    • http.request.method == "POST" or http.request.method == "GET" - download file
    • http.content_type contains "application" - File sospetti nelle risposte (es. .exe .zip .pdf)
  • 6. ICMP - Scansioni o problemi di routing
    • icmp - Ping e ICMP
    • icmp.type == 3 -ICMP unreachable (possibile scanning o errori)
  • 7. TCP - Anomalie, attacchi, scansioni
    • tcp.flags.reset == 1 - reset sospetti (forzatura connessioni)
    • tcp.analysis.retransmission - Ritrasmissioni (DoS, congestione, MITM)
    • tcp.flags.syn == 1 and tcp.flags.ack == 0 - Handshake incompleti (SYN scan / port scan)
    • tcp.flags.syn == 1 and tcp.len == 0 - Possibile SYN Flood
  • 8. ARP - Spoofing o MITM
    • arp - ARP traffic
    • arp.duplicate-address-detected - ARP duplicate IP (possibile MITM)
  • 9. DHCP - Dispositivi non autorizzati
    • dhcp - Nuovi dispositivi in rete
    • bootp.option.type == 53 and bootp.option.value == 1 - Richieste DHCP sospette
  • 10. Ricerca di exfiltrazione
    • ip.dst != 192.168.1.0/24 - Traffico anomalo in uscita
    • http.request.method == "POST" and http.content_length > 50000 - Flussi POST grandi

Go > Go To Packet Inserisci il numero di un determinato pacchetto

Statistics > resolved Addressed > HostsThis option helps analysts identify IP addresses and DNS names available in the capture file by providing the list of the resolved addresses and their hostnames.

Statistics > Protocol Hierarchy This option breaks down all available protocols from the capture file and helps analysts view the protocols in a tree view based on packet counters and percentages. Thus analysts can view the overall usage of the ports and services and focus on the event of interest.

Statistic > Conversations Conversation represents traffic between two specific endpoints. This option provides the list of the conversations in five base formats; ethernet, IPv4, IPv6, TCP and UDP. Thus analysts can identify all conversations and contact endpoints for the event of interest.

Statistics > Endpoints The endpoints option is similar to the conversations option. The only difference is that this option provides unique information for a single information field (Ethernet, IPv4, IPv6, TCP and UDP ). Thus analysts can identify the unique endpoints in the capture file and use it for the event of interest.
Wireshark also supports resolving MAC addresses to human-readable format using the manufacturer name assigned by IEEE. Note that this conversion is done through the first three bytes of the MAC address and only works for the known manufacturers. When you review the ethernet endpoints, you can activate this option with the"Name resolution"button in the lower-left corner of the endpoints window.
