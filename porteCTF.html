[Porte Fondamentali]

Porte Fondamentali, utili per CTF:

Web Nei CTF spesso trovi pannelli admin, API o servizi nascosti qui.
80 (HTTP) → traffico web non cifrato
443 (HTTPS) → web sicuro (SSL/TLS)
8080 / 8000 → web alternativi / dev server

Accesso remoto SSH è una delle porte più attaccate/bruteforzate.
22 (SSH) → login remoto Linux
23 (Telnet) → vecchio e insicuro (ma nei CTF appare spesso!)
3389 (RDP) → desktop remoto Windows

File transfer FTP anonimo (username: anonymous, password: qualsiasi cosa e il server potrebbe lasciarti entrare)
21 (FTP) → trasferimento file (spesso mal configurato)
20 (FTP data)
69 (TFTP) → versione semplice (senza auth)

Email
25 (SMTP) → invio email
110 (POP3) → ricezione (vecchio)
143 (IMAP) → gestione mailbox
465 / 587 / 993 / 995 → versioni sicure

Database Se esposti = spesso vulnerabilità o credenziali deboli.
3306 (MySQL)
5432 (PostgreSQL)
1433 (Microsoft SQL Server)
27017 (MongoDB)

Networking / infrastruttura
53 (DNS) → risoluzione nomi
67/68 (DHCP) → assegnazione IP
123 (NTP) → sincronizzazione oraria

Condivisione file / Windows SMB è una miniera nei CTF (enum, exploit, ecc.)
139 (NetBIOS)
445 (SMB)

Altre importanti
111 (RPCbind) → servizi RPC
135 (MS RPC)
6379 (Redis) → spesso senza auth
9200 (Elasticsearch) → spesso esposto
25xx / 3000 / 5000 / 7001 → app custom
